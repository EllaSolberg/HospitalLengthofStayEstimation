# Hvordan kjøre prosjektet: 

Filen prosjekt.ipynb kan kjøres fra start til slutt. I filen predictions.csv ligger alle prediksjoner på sample data. Koden for opprettelsen av den filen ligger i predict.ipynb. Koden for nettsiden ligger i templates/index.html og app.py. Nettsiden kan aktiveres ved hjelp python app.py i terminalen. 

# Hvordan bruke nettside: 

Nettsiden fungerer slik at du må skrive inn alle variablene som er oppgitt. Her er det viktig å regne de ut på anvist måte. De variablene som er valgt ut er de viktigste for å utføre prediksjonen. Resten av variablene regnes ut med en mean verdi som fylles ut automatisk. Dette er for å sikre god brukervennlighet. Hvis jeg hadde hatt bedre tid hadde jeg løst dette på en annen måte
